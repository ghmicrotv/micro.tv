# Micro.tv — подробная установка и запуск

Локальный кликабельный прототип стримингового сайта короткометражек и микро-сериалов в дизайне «Г · Плёнка».

| Раздел | Адрес | Что внутри |
|---|---|---|
| Кинотеатр | `/` | «Трейлер недели», «Новое в библиотеке» с фильтрами, «Катушки» |
| Лента | `/trailers` | вертикальная лента трейлеров с видео, фильтры, «Хочу посмотреть» |
| Профиль | `/profile` | «Продолжить просмотр», списки, редактирование профиля |

План и решения — [10_Prototype_Plan.md](10_Prototype_Plan.md), журнал изменений — [09_Dev_Log.md](09_Dev_Log.md).

## 1. Что нужно установить

| Инструмент | Версия | Проверка |
|---|---|---|
| [Go](https://go.dev/dl/) | 1.26 или новее | `go version` |
| [Node.js](https://nodejs.org/) (вместе с npm) | 20 или новее | `node --version` |
| Git | любая | `git --version` |

Больше ничего не нужно: база данных — файл SQLite, он создаётся сам при первом запуске. Docker, PostgreSQL и FFmpeg не нужны.

> Команды ниже написаны для bash (Linux, macOS, Git Bash на Windows). Отличия для PowerShell отмечены отдельно.

## 2. Получить код

```bash
git clone <адрес-репозитория> KinoSite
```

```bash
cd KinoSite
```

### Видео

Видеофайлы не хранятся в git. Положите папку `Media/` в корень проекта, рядом с `apps/`:

```text
KinoSite/
├── apps/
├── docs/
└── Media/
    ├── Films/
    │   ├── Ракка/…mp4
    │   └── Кожа/…mp4
    └── Serials/
        ├── colectors/…mp4
        └── дорога в пустоту/…mp4
```

Пути к файлам прописаны в `apps/api/internal/store/seed.json` (поле `"video"`). Если папки нет, сайт работает, но вместо видео у этих трейлеров будут абстрактные заглушки.

## 3. Установить зависимости

Бэкенд (Go-модули):

```bash
cd apps/api && go mod download
```

Фронтенд (npm-пакеты строго по `package-lock.json`):

```bash
cd apps/web && npm ci
```

Обе команды запускаются из корня проекта.

> npm 11 может написать `npm warn allow-scripts sharp…`. Это безопасно: сайт собирается и работает без этого скрипта, ничего подтверждать не нужно.

## 4. Запустить (режим разработки)

Нужны два терминала, оба открыты в корне проекта.

**Терминал 1 — API** (порт 8080):

```bash
cd apps/api && go run ./cmd/api
```

При первом запуске API создаёт базу `apps/api/data/kadr.db` и заполняет её демо-данными из `seed.json`.

**Терминал 2 — сайт** (порт 3000):

```bash
cd apps/web && npm run dev
```

Откройте **http://localhost:3000**. Вход выполняется автоматически под демо-пользователем «Мария К.».

Сайт сам проксирует запросы `/api/*` на `localhost:8080`, поэтому API должен быть запущен.

## 5. Запуск как в продакшене (сборка)

Собрать и запустить API:

```bash
cd apps/api && go build -o bin/api ./cmd/api
```

```bash
cd apps/api && ./bin/api
```

На Windows бинарник называется `bin/api.exe`.

Собрать и запустить сайт:

```bash
cd apps/web && npm run build
```

```bash
cd apps/web && npm run start
```

> Не запускайте `npm run build`, пока работает `npm run dev`: обе команды пишут в папку `apps/web/.next`, и dev-сервер после этого перестаёт работать. Остановите его, соберите проект и запустите заново.

## 6. Настройки (переменные окружения)

Все необязательные, значения по умолчанию подходят для локального запуска.

| Переменная | Для чего | По умолчанию |
|---|---|---|
| `KADR_ADDR` | адрес и порт API | `:8080` |
| `KADR_DATA` | папка с базой и аватарами (относительно `apps/api`) | `data` |
| `KADR_MEDIA` | папка с видео (относительно `apps/api`) | `../../Media` |
| `API_ORIGIN` | куда сайт проксирует `/api/*` | `http://localhost:8080` |

Пример: API на другом порту.

```bash
cd apps/api && KADR_ADDR=:9090 go run ./cmd/api
```

```bash
cd apps/web && API_ORIGIN=http://localhost:9090 npm run dev
```

В PowerShell переменная задаётся отдельной командой перед запуском: `$env:KADR_ADDR=":9090"`.

## 7. Полезные команды

Сменить «Трейлер недели» (герой на «Кинотеатре»). Аргумент — slug тайтла из `seed.json`:

```bash
cd apps/api && go run ./cmd/admin hero ogni-porta
```

Сбросить демо-данные (лайки, списки, профиль, аватар). Остановите API, удалите папку с базой и запустите API снова:

```bash
rm -rf apps/api/data
```

В PowerShell: `Remove-Item -Recurse -Force apps/api/data`.

База также пересоздаётся сама, если в коде поднята версия схемы (`schemaVersion` в `apps/api/internal/store/store.go`) — так делается после изменений `schema.sql` или `seed.json`.

Проверки перед коммитом:

```bash
cd apps/api && go vet ./... && go build ./...
```

```bash
cd apps/web && npx tsc --noEmit && npm run lint
```

## 8. Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| «Не удалось загрузить» на сайте | API не запущен — запустите терминал 1 |
| `address already in use` / порт занят | порт 8080 или 3000 занят другим процессом: остановите его или задайте другой порт (раздел 6) |
| Вместо видео абстрактные картинки | нет папки `Media/` в корне или файлы лежат не по путям из `seed.json` |
| Сайт перестал открываться после `npm run build` | остановите `npm run dev`, удалите `apps/web/.next` и запустите `npm run dev` снова |
| Ошибка про версию Go при сборке | обновите Go до 1.26+ |

## 9. Структура проекта

| Путь | Что |
|---|---|
| `apps/api` | Go API: chi, SQLite (`modernc.org/sqlite`, без CGO). Схема и демо-данные встроены в `internal/store` |
| `apps/api/cmd/api` | запуск API |
| `apps/api/cmd/admin` | команды администратора (`hero`) |
| `apps/web` | сайт: Next.js 15 + Tailwind CSS v4, токены дизайна в `app/globals.css` |
| `Media/` | видео трейлеров (не в git) |
| `docs/` | архитектура, план, журнал изменений (Obsidian) |
